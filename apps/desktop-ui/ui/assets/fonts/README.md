# Fontes do tema Orbital Command

Outfit (títulos), Manrope (corpo) e JetBrains Mono (dados) são as famílias já usadas pelo frontend do MLX-Pilot. As versões variáveis locais permitem a mesma tipografia sem chamadas ao Google Fonts.

Origem: [google/fonts](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl), revisão `47d54ca1ebb14fd864695f1d39dc734f39017c33`. Os TTF foram convertidos sem subsetting para WOFF2 usando FontTools 4.67.0/Brotli. As licenças SIL Open Font License 1.1 de cada família acompanham os arquivos.

Para usar, carregue `fonts.css` antes dos estilos do aplicativo ou da apresentação. Não é necessário instalar as fontes no computador.
