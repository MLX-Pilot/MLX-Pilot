# MLX-Pilot Skill Registry

This directory contains all registered skills for the MLX-Pilot agent.

## How to register a new skill

1. Create a new directory under `.agents/skills/<skill-name>/`
2. Add a `SKILL.md` file with:
   - Name and description
   - Usage instructions
   - Implementation details
3. (Optional) Add handler scripts in the same directory
